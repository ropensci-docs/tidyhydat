# DATA SYMBOLS look-up table

A look table for data symbols

## Usage

``` r
hy_data_symbols
```

## Format

A tibble with 5 rows and 3 variables:

- **SYMBOL_ID**: Symbol code

- **SYMBOL_EN**: Description of Symbol (English)

- **SYMBOL_FR**: Description of Symbol (French)

## Source

HYDAT
